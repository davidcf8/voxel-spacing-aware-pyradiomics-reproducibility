# Audit Notes

This directory records provenance and release-preparation notes for the public reproducibility repository.

The repository is limited to synthetic software-validation material. It excludes clinical CT/MRI cohort data, private external cohort data, raw patient images, manuscript source files, and journal-submission drafting material.

The implementation snapshot documents the voxel-spacing-aware technical extension and should remain separate from any future upstream PyRadiomics pull-request repository.
