# How to use the additional validation insert

Paste `experiments/manuscript_insert_additional_validation.tex` into the technical paper after the current software-validation methods/results section.

Recommended main-paper figures:
- `experiments/resampling_baseline_comparison/figures/heatmap_method_similarity.pdf`
- `experiments/computational_profiling/figures/runtime_vs_expansion_factor.pdf`

Recommended main-paper table:
- `experiments/table_additional_validation_summary.tex`

Keep the remaining CSVs and figures as supplementary or reviewer-response material.

Suggested replacement:
- Replace any broad claim that spacing-aware extraction is clinically superior with the narrower wording that it is an interpolation-free computational alternative whose software behavior was verified in synthetic phantoms.
- Replace any unsupported IBSI wording with: "spacing-aware outputs are descriptor extensions rather than IBSI reference values."
